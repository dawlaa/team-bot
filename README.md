# بوت تيم الكونتنت — نقاط الفويس + متجر + تيكيتات + ورنات + لوجات

## التشغيل

1. https://discord.com/developers/applications → Application جديد → تبويب **Bot** → خد التوكن.
2. في نفس التبويب فعّل **Server Members Intent** (ضروري).
   - اختياري: **Message Content Intent** + `MESSAGE_CONTENT=1` في `.env` (للترانسكريبت في التيكيتات ولوج تعديل/مسح الرسائل بمحتواها).
3. **OAuth2 > URL Generator**: `bot` + `applications.commands`. الصلاحيات: View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Manage Channels (للتيكيتات), Manage Roles (لمنتجات الرولات), Moderate Members (لتايم أوت الورنات).
4. (Python 3.10+):
   ```
   pip install -r requirements.txt
   cp .env.example .env     # حط التوكن
   python bot.py
   ```
5. لازم يفضل شغال طول الوقت (VPS أو جهاز شغال). لو وقع، الجلسة بتكمل لما يرجع، بس وقت الوقوع مابيتحسبش.

> البوت لازم يشوف الفويسات (View Channel). وللمنتجات اللي بتدّي رول: رول البوت لازم يكون أعلى من الرول ده.

## أسرع بداية
```
/settings log_channel   ← روم لوج افتراضي
/channels add           ← الفويسات اللي تتحسب
/settings rate 25       ← نقاط/ساعة
/settings money 0.5     ← قيمة النقطة بالفلوس
/panel                  ← لوحة التحكم (بتفتح كل حاجة بأزرار)
/start
```

## لوحة التحكم `/panel`
إمبيد واحد فيه قايمة أقسام (الرئيسية، الفويسات، النقاط، الفلوس، البوستات، المتجر، التيم، اللوجات والإمبيد) وأزرار كل قسم بتفتح نماذج جاهزة. انشرها في روم خاص بالإدارة (أو `private: True`). الأزرار شغالة حتى بعد ريستارت البوت، وبتتجاهل أي حد مش مسؤول.

## الأنظمة

**1) بوستات (نقاط مضاعفة)** — `/boost add` بالوقت والأيام والتواريخ (مثال: ×2 الجمعة والسبت 18:00–23:00)، `/boost now ×2 60` لبوست فوري، `/boost list|remove|toggle`. لو أكتر من بوست اشتغل، بياخد الأعلى (مش بيتضرب). التوقيت: `/settings timezone` (الافتراضي القاهرة).

**2) تقرير تلقائي** — `/autoreport set` (روم + أسبوعي/شهري + اليوم + الساعة + قفل الفترة تلقائيًا أو لأ)، `/autoreport now|status|off`. بيبعت إمبيد ملخص + ملف CSV.

**3) الفلوس** — `/settings money` قيمة النقطة، `/pay add` تسجيل دفع، `/pay summary` المدفوع والمتبقي للكل، `/pay history|undo`. `/me` بيوري للعضو مستحقاته. لما تقفل الفترة (`/period close`) المتبقي بيترحّل للفترة الجاية.

**4) معدلات خاصة** — `/rates set_channel` (فويس أو كاتيجوري)، `/rates set_role`. الأولوية: **الفويس ← الرول (الأعلى) ← العام**.

**5) الأشخاص** — `/people add user [فويسات]` يحدد مين بيتحسب وفي أنهي فويسات بالظبط، `/people mode whitelist` (المضافين بس) أو `everyone`، `/people block` لاستبعاد حد.

**6) المتجر** — `/shop add` (منتج بسعر نقاط، مخزون، ورول اختياري يتسلم أوتوماتيك)، `/shop panel` بانل بزرار، `/store` للأعضاء. الطلبات بتوصل لروم (`/shop orders_channel`) بزرارين تم التسليم / رفض واسترجاع، والعضو بيوصله DM. النقاط المصروفة بتتخصم من الرصيد المتاح (والترتيب بيفضل على إجمالي اللي اتكسب).

**7) التيكيتات** — `/ticket setup` (كاتيجوري + رول الدعم) ثم `/ticket panel`. زرار فتح بنموذج، استلام، `/ticket add|remove|close`، وعند الإغلاق بيتبعت ترانسكريبت للوج والـ DM.

**8) الورنات** — `/warn add` (مع خصم نقاط اختياري)، `list|remove|clear`، `/warn config` (الحد، تايم أوت تلقائي، خصم افتراضي، صلاحية الورن بالأيام)، `/mywarns` للعضو.

**9) الإمبيد** — `/embed send|edit|field_add|field_remove|json`.

**10) اللوجات** — `/logs set` روم لكل قسم (النقاط، الفويس، المدفوعات، المتجر، التيكيتات، الورنات، الإعدادات، الأعضاء، الرسائل، السيرفر)، `set_all`، `toggle`، `list`. بيسجل كمان دخول/خروج الفويس ومدة القعدة، تعديل/مسح الرسائل، دخول/خروج الأعضاء والرولات والأسماء، والبان.

## ملاحظات
- أي أمر إدارة متاح للأدمن / Manage Server / رول `/settings manager_role`.
- `/me` `/top` `/store` `/myorders` `/mywarns` متاحة للكل.
- لوج مسح الرسائل بيشوف محتوى الرسائل المحفوظة عند البوت بس.
- لو غيرت قيمة النقطة، بتتحسب بالقيمة الجديدة على الرصيد الحالي. اللي اتقفل في فترات سابقة بيفضل كما هو.
